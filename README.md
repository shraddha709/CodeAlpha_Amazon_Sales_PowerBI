# Amazon Sales Power BI Dashboard

## Project Overview
This project was completed as part of the CodeAlpha Data Analytics Internship. It presents an interactive Power BI dashboard built using the Amazon Sales dataset.

## Dashboard Features
- Total Sales
- Total Orders
- Total Quantity
- Average Sales
- Sales by Category
- Sales by State
- Order Status Analysis
- B2B vs B2C Analysis
- Monthly Sales Trend

## Tools Used
- Power BI
- Microsoft Excel / CSV
- DAX

## Key Insights
- Identified the highest-selling product categories.
- Analyzed sales performance across different states.
- Compared B2B and B2C orders.
- Monitored monthly sales trends and order status.
